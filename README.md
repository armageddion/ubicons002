# ubicons002

Combined dietary/allergen icon images. Each PNG in the project root is built
from up to **5** of the 16 icons in [`src/`](src/) (source icons, generated by
[`src/icon_combine.py`](src/icon_combine.py)).

## ICON MAP

Every generated image is named by a 16-character code. Each character
corresponds to one icon in order, left to right:

`X` = icon IS present in the image, `O` = icon is NOT present.

The first seven positions are fixed to the requested diet/allergen order:
Vegetarian, Vegan, No Alcohol, No Dairy, No Gluten, No Nuts, and Halal.
The remaining nine icons follow the remaining deterministic order.

| Index | Filename char | Icon file            |
|------:|:-------------:|----------------------|
|   00  | 1st           | Icon_Vegetarian.png  |
|   01  | 2nd           | Icon_Vegen.png       |
|   02  | 3rd           | Icon_NoAlcohol.png   |
|   03  | 4th           | Icon_NoDairy.png     |
|   04  | 5th           | Icon_NoGluten.png    |
|   05  | 6th           | Icon_NoNuts.png      |
|   06  | 7th           | Icon_Halal.png       |
|   07  | 8th           | Icon_Ketogenic.png   |
|   08  | 9th           | Icon_NoEggs.png      |
|   09  | 10th          | Icon_NoFish.png      |
|   10  | 11th          | Icon_NoMustard.png   |
|   11  | 12th          | Icon_NoPeanuts.png   |
|   12  | 13th          | Icon_NoPork.png      |
|   13  | 14th          | Icon_NoSesame.png    |
|   14  | 15th          | Icon_NoShellfish.png |
|   15  | 16th          | Icon_NoSoy.png       |

## HOW TO USE

1. A filename is 16 letters. The FIRST letter is index 0, the LAST is index 15.
2. For every position holding `X`, that icon is shown in the image.
3. Icons are laid out left to right in ascending index order, right-aligned
   on the 400x41 black canvas.

### Examples

| Filename code      | Indices        | Icons                                                         |
|--------------------|----------------|---------------------------------------------------------------|
| `XOOOOOOOOOOOOOOO` | 00             | Icon_Vegetarian                                               |
| `OXOOOOOOOOOOOOOO` | 01             | Icon_Vegen                                                    |
| `OOXOOOOOOOOOOOOO` | 02             | Icon_NoAlcohol                                                |
| `OOOXOOOOOOOOOOOO` | 03             | Icon_NoDairy                                                  |
| `OOOOOOOOOOOOOOOX` | 15             | Icon_NoSoy                                                    |
| `XOXOOOOOOOOOOOOO` | 00, 02         | Icon_Vegetarian, Icon_NoAlcohol                                |

## Regenerating

```sh
cd src
python3 icon_combine.py
```

Writes all 6,884 combinations (1–5 icons) to the project root.
